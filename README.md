# Retail Sales Business Analysis Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard built to analyze retail sales performance using the Superstore dataset. The dashboard provides insights into revenue, profit, customer purchasing patterns, regional performance, shipping trends, and product category analysis to support business decision-making.

---

## Business Objectives

- Monitor overall business performance through key KPIs.
- Identify top-performing product categories.
- Analyze monthly sales trends.
- Compare regional sales performance.
- Understand shipping mode distribution.
- Enable interactive filtering for deeper analysis.

---

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Sales by State (Map)
- Sales by Ship Mode
- Sales by Sub-Category
- Interactive Slicers
  - Region
  - Category
  - Segment
  - Order Date
